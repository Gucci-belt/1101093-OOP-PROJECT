# 🥗 ระบบสั่งอาหารเพื่อสุขภาพ + คำนวณ BMI

ระบบสั่งอาหารออนไลน์ที่ช่วยให้คุณเลือกอาหารที่ดีต่อสุขภาพ พร้อมคำนวณ BMI และแนะนำอาหารตามปัญหาสุขภาพ

พัฒนาโดยใช้ Java Spring Boot (Backend) และ HTML/CSS/JavaScript (Frontend)

---

## 📦 สิ่งที่ต้องเตรียมก่อนเริ่ม

- **Java JDK 17** ขึ้นไป (ถ้ายังไม่มีให้โหลดจาก Oracle หรือ OpenJDK)
- **Web Browser** ตัวไหนก็ได้ (Chrome, Edge, Firefox แนะนำ)
- **Internet** (ใช้โหลดฟอนต์และบางอย่างจาก CDN)

---

## 🚀 วิธีรันโปรแกรม

### ขั้นตอนที่ 1: เปิด Backend

Backend เป็นส่วนที่ทำงานเบื้องหลัง ต้องเปิดไว้ตลอดตอนใช้งานนะ

**วิธีรัน (แนะนำ): ใช้ Command Line**
1. เปิด Command Prompt หรือ Terminal
2. เข้าไปที่โฟลเดอร์ backend:
   ```cmd
   cd oop-backend
   ```
3. รันคำสั่ง:
   - **Windows:**
     ```cmd
     .\mvnw.cmd spring-boot:run
     ```
   - **Mac/Linux:**
     ```bash
     ./mvnw spring-boot:run
     ```
4. รอสักครู่... จนเห็นข้อความประมาณว่า `Started OopBackendApplication in X seconds` แปลว่ารันสำเร็จแล้ว

**หรือถ้าอยากใช้ IDE:**
- เปิด VS Code หรือ IntelliJ
- เปิดโฟลเดอร์ `oop-backend`
- เปิดไฟล์ `OopBackendApplication.java` แล้วกด Run

### ขั้นตอนที่ 2: เปิด Frontend

1. ไปที่โฟลเดอร์ `oop-frontend`
2. เปิดไฟล์ `login.html` ด้วยเบราว์เซอร์ (ดับเบิลคลิกหรือลากไปวางในเบราว์เซอร์)
3. เสร็จแล้ว! 🎉

## 📱 วิธีใช้งาน

### เข้าสู่ระบบ

มีบัญชีทดสอบให้ใช้:
- **Admin:** username `admin` / password `admin`
- **Member:** username `member` / password `123`

หรือกดปุ่ม "ลงทะเบียน" เพื่อสร้างบัญชีใหม่

### หน้าหลัก (Home)

- **ดูรายการอาหาร** พร้อมข้อมูลโภชนาการ (แคลอรี่, ไขมัน, น้ำตาล, โซเดียม)
- **ค้นหาอาหาร** พิมพ์ชื่ออาหารหรือคำที่อยากหา เช่น "ไขมันน้อย" หรือ "แคลอรี่เยอะ"
- **กรองอาหาร** ตามปัญหาสุขภาพ (เบาหวาน, ความดันสูง, ลดน้ำหนัก, ไขมันในเลือดสูง)
- **เรียงลำดับ** ตามแคลอรี่, ไขมัน, น้ำตาล, โซเดียม
- **สุ่มเมนู** กดปุ่ม "สุ่มเมนู" เพื่อเสี่ยงดวง
- **Food Battle** เปรียบเทียบอาหารสองอย่างดูว่าอันไหนดีกว่า
- **ค้นหาประวัติ** หาประวัติ BMI และการกินย้อนหลัง
- **เพิ่มลงตะกร้า** กดปุ่ม `+` ตรงอาหารที่อยากได้

### ตะกร้าสินค้า (Cart)

- ดูรายการที่เลือกไว้
- ลบรายการที่ไม่ต้องการ
- กด "ชำระเงิน" เมื่อพร้อม (เป็นแค่การจำลองนะ ไม่ได้ชำระเงินจริง)

### แดชบอร์ดสุขภาพ (Health Dashboard)

- กดไอคอน 📊 ที่เมนูด้านล่าง
- ดูสถิติการกินของวันนี้
- คำนวณ BMI (ใส่น้ำหนักและส่วนสูง)
- ดูคำแนะนำสุขภาพ

### ค้นหาประวัติสุขภาพ

- ไปที่หน้า "ค้นหาประวัติ" (Health History Search)
- หาประวัติ BMI และการกินตามวันที่
- ค้นหาด้วยคำสำคัญ
- ดูสรุปประวัติย้อนหลัง

## ❓ ปัญหาที่เจอบ่อย

**Q: กด Login แล้วไม่ขึ้นอะไร / ไม่เห็นรายการอาหาร**
- เช็คว่า Backend รันอยู่หรือยัง (ดูหน้าต่าง Terminal/Command Prompt)
- เช็คว่า Port 8080 ถูกใช้อยู่หรือเปล่า (ถ้ามีโปรแกรมอื่นใช้อยู่ อาจต้องปิดก่อน)

**Q: รูปภาพไม่แสดง**
- เช็คอินเทอร์เน็ต (เพราะบางรูปมาจาก CDN)
- หรือเช็คชื่อไฟล์ในโฟลเดอร์ `images` ว่าตรงกับโค้ดหรือเปล่า

**Q: Backend รันแล้ว แต่ Frontend เชื่อมต่อไม่ได้**
- เช็คว่า Backend รันที่ Port 8080 จริงๆ
- เปิด Browser Console (F12) ดูว่ามี Error อะไร
- เช็คว่า CORS เปิดอยู่ (ถ้าเป็นปัญหานี้ มักจะเห็น Error ใน Console)
